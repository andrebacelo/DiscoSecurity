## Descrição do jogo
- **Género:** jogo de decisão/reação sob tempo, com uma fase de plataformas.
- **Objetivo:** és o segurança à porta de uma discoteca. Decides quem entra ou é
  barrado segundo as regras do dia, que vão mudando ao longo do jogo. Se deixares
  entrar alguém proibido, tens de o perseguir numa fase de plataformas para o
  expulsar e recuperar.
- **Regras:** cada cliente tem de cumprir todas as regras ativas (mostradas no
  ecrã). A decisão é feita dentro de um tempo limite por cliente.
- **Estado de jogo:** pontuação + vidas (strikes). Sem vidas ou com o tempo
  esgotado = Game Over.
- **Condições de fim:** Game Over com reinício.

## Como executar
O jogo precisa de ser servido por HTTP local.

1. **Opção simples (VSCode):** instalar a extensão _Live Server_, clicar com o
   botão direito em `index.html` → _Open with Live Server_.
2. **Alternativa:** correr `npx serve` na raiz do projeto e abrir o endereço
   indicado no terminal.
